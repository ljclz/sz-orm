启动健康检查 HTTP server

在指定地址暴露健康检查端点，返回各资源池的 HealthReport JSON 数组。 HTTP 状态码：全部健康返回 200，任一不健康返回 503。

§参数

  • checker: 健康检查器（ wrapped in Arc 以便跨 task 共享）
  • pools: 需要检查的资源池名称列表
  • addr: 监听地址
