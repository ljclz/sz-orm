事务中间件

在请求处理前从连接池获取连接并开启事务； 请求处理完成后：

  • 响应状态为 2xx → 提交事务
  • 响应状态非 2xx → 回滚事务

§用法

ⓘ
use axum::middleware::from_fn_with_state;
use sz_orm_axum::{PoolState, transaction_layer};

let app = Router::new()
    .route("/", get(handler))
    .layer(from_fn_with_state(state.clone(), transaction_layer))
    .with_state(state);
