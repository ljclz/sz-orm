Derive Macro ColumnEnum 

Source 
#[derive(ColumnEnum)]
{
    // Attributes available to this derive:
    #[column]
}
Expand description

Derive macro: auto-generates a <StructName>Column column-name enum from struct fields (P2-2).

Each field produces a variant (snake_case → CamelCase); ColumnTrait::as_str() returns the database column name; #[column(name = "...")] can override the column name (consistent with FromQueryResult). Also implements std::fmt::Display.

§Example

ⓘ
use sz_orm_macros::ColumnEnum;
use sz_orm_core::ColumnTrait;

#[derive(ColumnEnum)]
struct User {
    id: i64,
    #[column(name = "user_name")]
    name: String,
}

assert_eq!(UserColumn::Id.as_str(), "id");
assert_eq!(UserColumn::Name.as_str(), "user_name");
assert_eq!(UserColumn::Id.to_string(), "id");
