§SZ-ORM WASM — WASM Query Interface (experimental, not for production use)

Provides lightweight query capabilities for browser-side use, with built-in in-memory database and SQL subset parsing, suitable for local querying and demonstrations without backend dependencies.

§Main Types

  • WasmQuery — Query request (SQL + parameters)
  • In-memory database — Supports local execution of SQL subset
  • advanced — Memory limits, WASI sandbox, async scheduling, module cache
