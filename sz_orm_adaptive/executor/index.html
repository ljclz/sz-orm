sz_orm_adaptive

Module executor 

Source
Expand description

自适应执行器：决策（decide）+ 统计记录（record）+ 缓存执行（execute_cached）

设计说明：

  • 本模块只做决策层，不重写分页/缓存实现——调用方按 ExecutionPath 复用既有 sz-orm-core 的 cursor_stream / paginator / l2_cache
  • 自动缓存默认关闭（AdaptiveConfig::cache_enabled，防脏读，需显式开启）
  • 慢查询不做强行中断（Rust 同步闭包无法安全取消），以结构化标记输出
