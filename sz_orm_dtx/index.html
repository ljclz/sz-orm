§SZ-ORM DTX — Distributed Transactions

Provides cross-service distributed transaction coordination capabilities, including Saga, TCC, and cross-shard transaction patterns, supports participant state machines and rollback callbacks.

§Main Modules

  • saga — Saga long transaction orchestration
  • tcc — Try-Confirm-Cancel three-phase commit
  • cross_shard — Cross-shard transaction coordination
