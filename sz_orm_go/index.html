§SZ-ORM Go Bindings

Provides sz-orm-core’s Pool/Query API to Go via cgo / syscall (SQLite backend, real and usable).

Go side wrapper (go/szorm/) uses Windows syscall.NewLazyDLL to load sz_orm_go.dll and call functions exported by this crate; non-Windows platforms use cgo.
