1//! # sz-orm-adaptive — Runtime Adaptive Query Optimizer
2//!
3//! Lightweight runtime adaptation without AI dependencies: collects query statistics (atomic counters, lock-free),
4//! automatically switches execution paths based on thresholds:
5//!
6//! - **Auto pagination**: Average row count exceeds threshold → suggest switching to cursor pagination
7//! - **Hot cache**: Slow query + high frequency → auto read cache (requires explicit enable, prevents dirty read)
8//! - **Slow query marker**: Single execution timeout threshold → mark slow and return structured info
9//!
10//! Typical usage (with existing `sz-orm-core` `cursor_stream` / `l2_cache`):
11//!
12//! ```rust,ignore
13//! let executor = AdaptiveExecutor::new(AdaptiveConfig::default());
14//! match executor.decide("find_users") {
15//!     ExecutionPath::Paginated => { /* use cursor_stream for cursor pagination */ }
16//!     _ => { /* normal query */ }
17//! }
18//! executor.record("find_users", rows, elapsed_ms);
19//! ```
20//!
21//! This package has zero dependency on `sz-orm-core`: the decision layer only does statistics and suggestions,
22//! the actual execution paths (cursor pagination / cache write) are completed by the caller reusing existing implementations, avoiding circular dependencies.
