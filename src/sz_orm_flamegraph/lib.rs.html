1//! # sz-orm-flamegraph — Query Performance Flamegraph
2//!
3//! Collects timing for each query phase (query construction / parameter binding / connection pool acquire / SQL execution / result mapping),
4//! outputs Brendan Gregg folded format (`flamegraph.pl` compatible) and inline SVG flamegraph.
5//!
6//! ```rust
7//! use sz_orm_flamegraph::{Phase, QueryTracer};
8//!
9//! let (result, timings) = QueryTracer::trace_execute(|rec| {
10//!     let sql = rec.record(Phase::Build, || "SELECT * FROM users".to_string());
11//!     let _rows = rec.record(Phase::SqlExecute, || 42usize);
12//!     sql
13//! });
14//! assert_eq!(result, "SELECT * FROM users");
15//! assert_eq!(timings.len(), 2);
16//! ```
17//!
18//! Output formats:
19//! - [`render::to_brendan_gregg`]: Folded stack format, can be directly fed to `flamegraph.pl`
20//! - [`render::to_svg`]: Self-rendered inline SVG (no external dependencies)
21//!
22//! When `query-flamegraph` feature is enabled, phase timing can be written to existing `sz-orm-tracing` `Tracer` spans
23//! via [`collector::QueryTracer::with_tracer`].
