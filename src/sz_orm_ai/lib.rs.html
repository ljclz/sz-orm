1//! # SZ-ORM AI — AI Capability Package
2//!
3//! Provides natural language to SQL (NL2SQL), retrieval-augmented generation (RAG), text embedding and vector search capabilities,
4//! with built-in safety protection and OpenAI-compatible API client (compiled when `real` feature is enabled).
5//!
6//! ## Main Modules
7//!
8//! - [`embedding`] — Text vectorization interface
9//! - [`nl2sql`] — Natural language to SQL conversion
10//! - [`rag`] — Retrieval-augmented generation
11//! - [`vector`] — Vector store and similarity search
12//! - [`safety`] — Input safety check
13//! - [`sql_sanitizer`] — SQL sensitive literal masking
14//!
15//! When `llm-optimizer` feature is enabled, additionally provides:
16//! - [`explain_parser`] — EXPLAIN execution plan parser (5 dialects)
17//! - [`query_plan_optimizer`] — Unified query plan optimizer (rules + LLM)
