1//! # sz-orm-fusion — Multi-Database Fusion Query (experimental, not for production use)
2//!
3//! **Experimental POC** — this package is an optional experiment for v4.3.0 M5.
4//! It is not intended for production use and may change or be removed in future versions.
5//!
6//! Transparent multi-database operations: query splitting, aggregation, and degradation for **primary + cache + search**.
7//! Specific backends (Redis / vector store) are injected via traits, not bound to implementations.
8//!
9//! Core concepts:
10//!
11//! - [`FusionQuery`]: Structured query description (table + parameterized equality conditions + other conditions)
12//! - [`FusionPlanner`]: Static analysis → [`FusionPlan`] (cache pushdown / search pushdown / primary steps)
13//! - [`FusionExecutor`]: Execute by plan, cache hit skips primary, primary failure falls back to cache
14//!
15//! ```text
16//! let config = FusionConfig {
17//!     primary: "mysql".into(),
18//!     cache: Some(CacheBackend::Memory),
19//!     search: None,
20//! };
21//! let ex = FusionExecutor::new(config).with_cache(Arc::new(MemoryFusionCache::new()));
22//! let q = FusionQuery::new("users").eq("id", "42");
23//! let out = ex.execute(&q, |q| primary_query(q)).unwrap();
24//! assert!(!out.degraded);
25//! ```
