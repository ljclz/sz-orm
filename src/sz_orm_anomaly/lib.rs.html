1//! # sz-orm-anomaly — Anomaly Detection
2//!
3//! Based on `anomaly-detection` feature, continuously collects database runtime metrics (slow query/error rate/connection pool),
4//! detects anomaly patterns (spike/exhaustion/baseline deviation) via sliding window + Welford online baseline + statistical rules + thresholds,
5//! outputs structured alert events, supports alert deduplication (cooldown), subscription callbacks, Prometheus metric export, and health integration.
6//!
7//! ## Design Principles
8//!
9//! - **Statistical rules + thresholds (non-ML)**: Based on mean + Nσ + absolute threshold, simple and interpretable, no training data needed
10//! - **Async/bypass collection**: Metric collection does not block query main path (REQ-ANM-005)
11//! - **Sliding window + time eviction**: Retains last N minutes of data (default 30 minutes), memory limit 10 MB
12//! - **Welford online algorithm**: Numerically stable, single update O(1), suitable for real-time baseline computation
13//! - **Alert deduplication cooldown**: Same-type anomalies do not repeat alert within 5 minutes, avoiding alert storms
14//! - **Feature gate isolation**: Disabled by default, does not affect existing compilation
15//!
16//! ## Main Modules
17//!
18//! - [`config`] — Threshold config + hot reload (`AnomalyConfig` + `ConfigStore`)
19//! - [`collector`] — Metric collection (`MetricCollector` + 3 metric types + SQL summary masking)
20//! - [`window`] — Sliding window (`SlidingWindow` + time eviction + memory limit protection)
21//! - [`detector`] — Anomaly detection (`BaselineCalculator` Welford + `SpikeDetector` + severity level determination)
22//! - [`alert`] — Alert output (`Alert` + `AlertDedup` cooldown + subscription API)
23//! - [`report`] — Report export (JSON + Markdown)
24//! - [`integration`] — Integration module (Prometheus metric export + health integration)
25//! - [`error`] — Error type
26//!
27//! ## Reuse
28//!
29//! - SQL masking reuses `sz-orm-masking::DataMasker` (parameter values → placeholders)
30//!
31//! ## Quick Start
32//!
33//! ```no_run
34//! # #[cfg(feature = "anomaly-detection")] {
35//! use sz_orm_anomaly::{AnomalyDetector, AnomalyConfig};
36//!
37//! let detector = AnomalyDetector::new(AnomalyConfig::default());
38//! detector.record_slow_query(150, "SELECT * FROM users WHERE id = ?", 0);
39//! detector.record_error(sz_orm_anomaly::ErrorType::SqlError, 0);
40//! detector.record_pool_usage(48, 2, 15, 1200, 0);
41//!
42//! let alerts = detector.detect_anomalies();
43//! for alert in &alerts {
44//!     println!("[{:?}] {:?}: {}", alert.severity, alert.anomaly_type, alert.suggestion);
45//! }
46//! # }
