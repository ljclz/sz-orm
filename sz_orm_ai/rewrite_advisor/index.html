查询重写建议模块

基于 sqlparser 解析 SQL 为 AST，识别可优化模式：

  • 谓词下推（Predicate Pushdown）
  • 子查询展开（Subquery Flattening）
  • JOIN 顺序调整（Join Reorder）
  • 冗余条件消除（Redundant Elimination）

产出重写建议 + 等价性论证，不自动重写。 启用 ai-rewrite-advisor feature 时编译。
