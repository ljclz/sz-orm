在真实 DB 上验证改写等价性

执行原 SQL 与改写 SQL，对比结果集。 is_equivalent == false 时调用方必须回退原 SQL 并告警 REWRITE_EQUIVALENCE_VIOLATION。

§参数

  • original_sql: 原 SQL
  • rewritten_sql: 改写后 SQL
  • executor: DB 执行器

§返回值

  • EquivalenceVerificationResult: 验证结果
