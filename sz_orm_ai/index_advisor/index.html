自动索引建议模块

基于查询模式分析和慢查询日志，自动生成索引建议。 使用 sqlparser 解析 SQL 提取 WHERE/JOIN/ORDER BY 列， 识别高频查询模式，生成 DDL 建议文本（不自动执行）。

启用 ai-index-advisor feature 时编译。
