§SZ-ORM Java Bindings

Calls sz-orm-cabi’s C ABI via JNI, providing Java with sz-orm-core’s Pool/Query API (SQLite backend, real and usable).

JNI symbol names follow javac -h generated sz_orm_java_SzOrmPool.h: Underscores in package name sz_orm_java are escaped as _1.
