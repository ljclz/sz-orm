DB Resolver trait — P2-1 修复 C-3

调用方实现此 trait，为 GraphQL root field 提供真实数据。

§方法

  • resolve_query：解析 Query 字段，返回单个对象或数组
  • resolve_mutation：解析 Mutation 字段，返回操作结果

§async 实现

使用 Pin<Box<dyn Future>> 返回异步结果，无需 async-trait 依赖。
