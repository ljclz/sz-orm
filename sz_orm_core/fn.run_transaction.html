v9.3.0：事务闭包模板（panic 安全回滚）

自动 begin_transaction + 应用隔离级别/只读 + catch_unwind 执行闭包； 闭包返回 Ok(Ok(v)) → commit，Ok(Err(e)) → rollback → Err(e)， Err(panic) → rollback → resume_unwind（panic 不吞没）。

§panic 安全保证

  • 闭包 panic → 自动 rollback → resume_unwind 传播原始 panic
  • rollback 失败 → tracing::error! 记录，panic 仍传播
  • 正常路径 → catch_unwind 零成本（无额外开销）
