v6.6.0 查询结果缓存（QueryResultCache）

缓存查询结果集（数据级别），带 TTL + LRU 淘汰 + 容量限制。 与 v6.5.0 的 PreparedStatementCache（句柄级别）互补： 查询流程：QueryResultCache → PreparedStatementCache → DB

§缓存键

(sql_hash, params_hash, tenant_id) 三元组，避免存储完整 SQL 字符串。

§失效策略

  • 被动失效：TTL 过期
  • 容量淘汰：LRU 策略
  • 主动失效：表写入触发相关查询缓存失效
