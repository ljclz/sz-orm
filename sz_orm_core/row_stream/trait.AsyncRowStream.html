Expand description

异步行流 trait

统一 MySQL/PG/SQLite/Oracle 流式查询接口。 消费方针对此 trait 编写代码，可在后端间切换。

§生命周期

next_row / close 借用 &mut self，返回 Pin<Box<dyn Future + Send + 'a>>。 签名遵循 Connection trait 的 Pin<Box<dyn Future>> 模式（HRTB 约束）。
