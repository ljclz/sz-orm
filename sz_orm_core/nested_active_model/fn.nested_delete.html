执行嵌套删除：删除顺序子先父后

  1. 开启事务
  2. 删除所有子实体（DELETE children WHERE fk = parent_id）
  3. 删除父实体（DELETE parent WHERE pk = parent_id）
  4. commit

若 cascade_delete 为 true，递归删除子级的子级。
