限流器抽象（P1-4：抽象提升到核心层，供连接池执行路径集成）

连接池在 rate-limit feature 下通过 set_rate_limiter() 配置限流器， 获取连接前调用 RateLimiter::try_acquire 检查是否放行。

本模块为自包含抽象（不依赖 sz-orm-limit），消除核心层对上层 crate 的反向依赖； 具体实现（滑动窗口/令牌桶等）由 sz-orm-limit 提供并实现本 trait。
