Expand description

Mock 数据库连接

用于单元测试，预设 SQL 查询的预期结果，无需真实数据库。

§事务模拟

MockConnection 会跟踪 begin/commit/rollback 调用状态， 可通过 was_committed() / was_rolled_back() 断言事务行为。
