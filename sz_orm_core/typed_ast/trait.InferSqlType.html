Expand description

Rust 类型 → SQL 类型标记推断 trait

为常见 Rust 类型提供编译期 SqlType 映射，使 typed_query! 宏能自动推断 列的 SqlType，而非一律默认 Untyped。

未实现此 trait 的类型在 typed_query! 宏中使用时会产生编译错误， 用户可自行实现 InferSqlType 来扩展类型映射。
