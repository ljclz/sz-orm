## 3. 方言专属特性清单

### 3.1 MySQL 专属

- **ON DUPLICATE KEY UPDATE**：MySQL 独有 upsert 语法，使用 `VALUES(col)` 引用插入值
- **LAST_INSERT_ID()**：连接级最后插入 ID，事务内可用
- **SQL_CALC_FOUND_ROWS / FOUND_ROWS()**：已废弃，建议用 `COUNT(*)` 替代
- **LOCK IN SHARE MODE**：MySQL 独有共享锁语法

### 3.2 PostgreSQL 专属

- **ON CONFLICT (cols) DO UPDATE SET**：PG 独有 upsert 语法，使用 `EXCLUDED.col` 引用插入值
- **SERIAL / BIGSERIAL**：旧式自增（已被 `GENERATED BY DEFAULT AS IDENTITY` 替代）
- **lastval()**：序列级最后插入值
- **FOR SHARE**：PG 独有共享锁语法

### 3.3 SQLite 专属

- **ON CONFLICT (cols) DO UPDATE SET**：与 PG 一致（SQLite 3.35+）
- **last_insert_rowid()**：进程级最后插入 rowid
- **无行级锁**：通过事务隔离级别（SERIALIZABLE）替代
- **内存模式**：`sqlite::memory:` 无需文件

### 3.4 Oracle 专属

- **RETURNING ... INTO :bind**：PL/SQL 子句，必须附加在 INSERT 末尾，不能独立执行
- **MERGE INTO**：Oracle 独有 upsert 语法（sz-orm 暂未封装，需手写 SQL）
- **OFFSET/FETCH NEXT**：12c+ 分页语法
- **SEQUENCE.NEXTVAL**：序列取值（与 IDENTITY 列并存）

### 3.5 MSSQL 专属

- **OUTPUT INSERTED.***：MSSQL 独有，语义等价于 RETURNING
- **MERGE INTO**：MSSQL 独有 upsert 语法（sz-orm 暂未封装，需手写 SQL）
- **SCOPE_IDENTITY()**：当前作用域内最后生成的标识值
- **WITH (UPDLOCK)**：MSSQL 独有行锁提示
- **OFFSET ... ROWS FETCH NEXT ... ROWS ONLY**：2012+ 分页语法

## 4. 跨方言兼容策略

### 4.1 RETURNING 回退

```rust
let dialect = pool.dialect();
if dialect.supports_returning() {
    // 使用 RETURNING / OUTPUT 子句获取插入数据
    sql = format!("INSERT INTO {} (...) VALUES (...) RETURNING *", table);
} else if let Some(last_id_sql) = dialect.last_insert_id_sql() {
    // MySQL/PG/SQLite/MSSQL 回退：先 INSERT 再查 last_insert_id
    sql = format!("INSERT INTO {} (...) VALUES (...)", table);
    let id = conn.query(last_id_sql).await?;
} else {
    // Oracle 回退：INSERT ... RETURNING {pk} INTO :bind
    sql = format!("INSERT INTO {} (...) VALUES (...) RETURNING {} INTO :id", table, pk);
}
```

### 4.2 Upsert 回退

```rust
if let Some(clause) = dialect.build_upsert_on_conflict(&conflict_cols, &update_cols, &all_cols) {
    // MySQL/PG/SQLite：使用 ON DUPLICATE KEY / ON CONFLICT
    sql = format!("INSERT INTO {} (...) VALUES (...) {}", table, clause);
} else {
    // Oracle/MSSQL：使用 MERGE INTO（需手写 SQL）
    sql = build_merge_sql(table, &conflict_cols, &update_cols, &all_cols);
}
```

### 4.3 行锁回退

```rust
if dialect.supports_lock_for_update() {
    // MySQL/PG/Oracle/MSSQL：追加 FOR UPDATE
    sql = format!("{} FOR UPDATE", sql);
} else {
    // SQLite：依赖事务隔离级别 SERIALIZABLE
    conn.execute("PRAGMA read_uncommitted = 0").await?;
}
```
