## 三、当前弱点分析

### 3.1 未完成的工程任务

| # | 弱点 | 影响 | 优先级 |
|---|------|------|--------|
| W1 | **sz-orm-graph 未发布到 crates.io** | 下游无法通过 crates.io 使用图数据库支持 | 高 |
| W2 | **sz-pay 下游回归未验证** | sz-pay 当前使用 2.3.0，v3.0.0 变更可能影响 | 高 |
| W3 | **性能基准未在 v3.0.0 上重跑** | 无法确认 v3.0.0 新增代码未导致性能回退 | 中 |
| W4 | **rdkafka-sys --all-features 编译失败** | Gate 10 无法通过（Windows 无 librdkafka C 库） | 低（预存） |
| W5 | **真实 DB 集成测试未执行** | M2.7/M5.10/M6.10 的 #[ignore] 测试未验证 | 中 |

### 3.2 功能层面的弱点

| # | 弱点 | 影响 | 优先级 |
|---|------|------|--------|
| F1 | **WASM 缺少 TypeScript 定义** | JS 用户无类型提示，开发体验差 | 中 |
| F2 | **LLM 优化器仅支持 OpenAI 兼容 API** | 不支持 Anthropic/Google Gemini/本地模型 | 低 |
| F3 | **GraphPool 使用 Mutex 而非真正连接池** | 高并发下性能瓶颈 | 中 |
| F4 | **XA 事务恢复仅测试 mock 参与者** | 未验证真实数据库 XA 支持 | 中 |
| F5 | **无查询结果缓存层** | 重复查询无加速 | 低 |
| F6 | **无流式查询支持** | 大结果集全量加载，内存压力大 | 低 |
| F7 | **无 OpenTelemetry 可观测性集成** | 生产环境缺乏链路追踪 | 低 |
