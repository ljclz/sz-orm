## 交付项 1：MCP stdio 传输层

**目标**：使 sz-orm-mcp 可作为 Claude/Cursor 等 AI 客户端的 MCP server 运行

### 代码

| 文件 | 内容 |
|------|------|
| `packages/sz-orm-mcp/src/stdio.rs` | `StdioTransport` struct + `run()` + `process_line()` |
| `packages/sz-orm-mcp/src/lib.rs` | 导出 stdio 模块 + `StdioTransport` |

### 测试

```
cargo test -p sz-orm-mcp --features mcp
```

输出：9 passed（server 5 + stdio 4）

### 生产入口

- `StdioTransport::new(server)` → `run()`：从 stdin 读取 JSON-RPC，处理后写入 stdout
- `process_line()`：pub 方法，处理单行 JSON-RPC 请求

### clippy

```
cargo clippy -p sz-orm-mcp --features mcp --all-targets --no-deps -- -D warnings
```

输出：Finished，0 警告
