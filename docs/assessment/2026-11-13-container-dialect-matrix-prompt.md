## 评测矩阵（每实例迷你矩阵 3~4 载荷，聚焦家族偏差点；三步 = 方言层生成 + 真库执行 + 行为断言）

### MZ-MSSQL（SqlServerDialect；integration_mssql 13 项不重复）
- `OUTPUT INSERTED.id`（sz-orm 主键回填通道 vs RETURNING）；`[方括号]` quoting；`TOP n` vs `OFFSET..FETCH`（要求 `ORDER BY` 前置！无 ORDER BY 的 OFFSET 报错）；`GETDATE()`/类型 `NVARCHAR(MAX)`

### MZ-MariaDB（MySqlDialect 委托；integration_mariadb 8 项不重复）
- 与 MySQL 的偏差点：`SEQUENCE`（MariaDB 有原生 SEQUENCE，MySQL 无）；`RETURNING`（10.5+ INSERT 支持，MySQL 无）；默认 sql_mode 差异；`CHECK 约束执行`（10.2+ 真执行，MySQL 8.0.16 前 defer）

### MZ-TiDB（MySqlDialect 委托；integration_tidb 8 项不重复）
- 家族偏差：外键（v6.6+ 真执行，旧版静默忽略——**探针 sz-orm FK 生成在 TiDB 的真实行为**）；`AUTO_RANDOM`（替代 AUTO_INCREMENT 的分布式主键）；`information_schema` 兼容面；无 CHECK 约束执行（旧版）

### MZ-ClickHouse（ClickHouseDialect；integration_clickhouse 11 项不重复）
- OLAP 面：`ENGINE=MergeTree`（DDL 生成面是否带引擎子句）；MySQL 协议通道的参数绑定；无事务回滚（探针 sz-orm 事务 API 在 CH 的行为契约——报错还是静默）

### MZ-DB2（Db2Dialect；integration_db2 11 项不重复）
- `SYSIBM.SYSDUMMY1`（FROM-less）；`FETCH FIRST n ROWS ONLY`（无 LIMIT/OFFSET 旧语法）；标识符 128 字节大写折叠（同 Oracle 向）；`GENERATED BY DEFAULT AS IDENTITY` 回填

### MZ-openGauss（GaussDBDialect 委托→PG 族；integration_gaussdb 8 项不重复）
- PG 族偏差：`B` 类型兼容模式（默认 Oracle 兼容模式 vs PG 模式的语法面）；`RETURNING`（openGauss 部分支持）；序列 `NEXTVAL` 通道；双引号折叠行为与 PG 的差异点

## 硬性要求

- **语义基准**：各引擎官方文档 + 真库实测；**禁止拿 MySQL/PG 互相仲裁**——家族委托正确性才是评测对象
- **sz-orm 方言缺口**：委托配置错误（如 TiDB 走错家族）/生成 SQL 被拒 → 修复 + 单测 + 真连断言；引擎自身限制（TiDB 无 CHECK、CH 无事务）登记为引擎特有
- **参数化铁律**（门禁 9）；零 unsafe、零 todo!
