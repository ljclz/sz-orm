## 2. Windows 环境限制

### 2.1 命令行长度限制

Windows 命令行最大长度约 32767 字符。cargo-llvm-cov 生成 lcov 报告时，将所有测试二进制文件作为 `-object` 参数传递给 `llvm-cov export`。sz-orm 工作空间有数百个测试二进制，命令行超过 Windows 限制：

```
error: failed to generate report: could not execute process `llvm-cov export ...`
(never executed): 文件名或扩展名太长。 (os error 206)
```

此限制影响所有 Windows 环境下的 cargo-llvm-cov 全工作空间报告生成，非 sz-orm 代码问题。

### 2.2 解决方案

- **Linux CI 环境**：覆盖率门禁 G22 使用 `scripts/collect-coverage-linux.sh`，在 Linux CI 环境执行，无此限制
- **分批脚本**：`scripts/collect-coverage-batch.sh` 在 Linux 环境可正常执行，每批 `-object` 参数数量可控
- **Windows 本机**：可使用 `cargo llvm-cov --no-report` 收集 profdata，再手动分批生成报告（本次不实施，标注为 CI 环境执行项）
