## 1. 交付目标

将 `build_select_with_params` SQL 构建吞吐从 v6.2.0 的 806K ops/s 提升到 ≥ 2M ops/s，缩小与 SQLx 4.6M ops/s 的 5.7x 差距到 ≤ 2.3x。同时完成 lib.rs 文档状态对齐（"prototype stage" → "production-ready"）。
