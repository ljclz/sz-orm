## 4. UTF-8 修复性能影响

### 修复内容

`sql_sanitizer.rs` 中 `sanitize_keyword` 和 `sanitize_base64_literals` 的 `bytes[i] as char` 改为 `sql[i..].chars().next().unwrap()` + `ch.len_utf8()`。

### 性能影响

- 对于 ASCII 输入（SQL 语句主体）：`chars().next()` 等价于 `bytes[i] as char`，无性能差异
- 对于非 ASCII 输入（中文自然语言）：修复了既有 bug，正确处理 UTF-8 字符
- 不影响热路径（SQL 脱敏仅在 LLM 调用前执行，非高频操作）
