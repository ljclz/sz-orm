- 变异注入（commit `fc03b78f`，2026-09-17 05:53:03 +0800）第 198 行为 `result.failed_keys -= /* ~ changed by cargo-mutants ~ */ 1;`（错误减法）
- 变异源：cargo-mutants 就地改写源码方法体注入变异体，跑完未恢复源码

**修复**：恢复为原始加法操作

## 经验教训

1. **变异测试后必须恢复源码**：cargo-mutants 就地改写源码方法体注入变异体，跑完必须 `git checkout` 恢复，否则污染后续门禁
2. **提交前检查 diff**：提交前应检查 `git diff` 是否包含 cargo-mutants 残留注释 `/* ~ changed by cargo-mutants ~ */`
