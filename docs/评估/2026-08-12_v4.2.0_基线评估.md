1. **框架真实性高**：所有核心模块、9 项 v4.0.0 能力、v4.1.0 基线能力真实存在，file:line 证据链基本可靠

## 3.2 已排除方向及理由

| 方向 | 排除理由 |
|------|---------|
| 编译期数据库（"编译即部署"） | 需将 `QueryBuilder`（运行时构造，`packages/sz-orm-core/src/query.rs:36`）前移编译期 = 重写 ORM 核心 |
| 类型级查询验证（const generics 全验证） | 需重构类型映射系统（`FromRow`/`Model` 运行时 trait），与"无 Breaking Change + sz-pay 兼容"铁律冲突 |
| 完全零开销数据访问 | 复杂动态查询无法编译期生成 SQL，只能部分优化（简单查询预生成 + FromRow 宏优化） |
