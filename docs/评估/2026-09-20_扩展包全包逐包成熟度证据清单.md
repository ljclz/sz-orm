## 三、2 个疑似 feature 接线点的最终裁决

批量扫描发现 `<feature 定义数 > 0 但 lib.rs 直接 cfg(feature) 引用 = 0>` 的可疑包共 **2 个**，逐一核实：

### 1. sz-orm-lc（`lc-bidirectional-sync` feature）—— 已排除，真实
- feature 定义：`lc-bidirectional-sync = ["dep:sz-orm-designer", "dep:tokio", ...]`（`sz-orm-lc/Cargo.toml`）
- 直接证据：源码存在 `sz-orm-lc/src/bidirectional_sync.rs`（双向同步引擎，非空，1242 行实现），`grep -l 'bidirectional'` 命中该文件与 lib.rs → **feature 有真实接线模块**。
- 判定：lib.rs 通过依赖 feature 而非本包内 `cfg` 引用，故首轮扫描未命中，属扫描方式误报。

### 2. sz-orm-n1-lint —— 已排除，真实
- feature 仅 1 个（`n1-lint` 转发至 sz-orm-macros），源码主扫描器 `scan_dir` 为无条件实现（`sz-orm-n1-lint/src/lib.rs:570` 自杀测试用临时目录）。
- 判定：该包核心功能不依赖本包 feature gate，属设计如此，非幻影。
