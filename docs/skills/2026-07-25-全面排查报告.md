## 二、详细结果

### Skill 1: SQL 生成变异测试

**执行命令**：
```
cargo mutants -f "packages/sz-orm-query-builder/src/lib.rs" -p sz-orm-query-builder
```

**结果**：

| 指标 | 数值 |
|------|------|
| 总变异体 | 91 |
| 捕获 | 76 |
| 存活（等价变异） | 4 |
| 不可编译 | 11 |
| **杀死率** | **95%** |

**存活的 4 个等价变异**（不可通过测试区分）：

| 位置 | 变异 | 原因 |
|------|------|------|
| lib.rs:131 | `Query::select()` → `SelectQuery` → `Default::default()` | `SelectQuery::new()` 直接调用 `Self::default()`，语义完全等价 |
| lib.rs:136 | `Query::insert()` → `InsertQuery` → `Default::default()` | 同上 |
| lib.rs:141 | `Query::update()` → `UpdateQuery` → `Default::default()` | 同上 |
| lib.rs:146 | `Query::delete()` → `DeleteQuery` → `Default::default()` | 同上 |

**补写测试**：新增 11 个针对性测试（`test_mutant_*`），杀死 7 个原先存活的逻辑变异体。

**结论**：所有行为可区分的变异体已全部杀死，有效杀死率 **100%**。

### Skill 4: API 反向破坏性审查

**审查文件**：`docs/skills/API_ATTACK_REPORT.md`

**结果**：1 🔴 红牌 + 4 🟡 黄牌 + 3 🟢 提示

| 严重性 | 数量 | 问题 |
|--------|------|------|
| 🔴 红牌 | 1 | `WithRelation<M>` 未显式标注 Send 边界 |
| 🟡 黄牌 | 4 | `ConstraintViolation` 未区分唯一/外键冲突；Transaction/PooledConnection 隐式 Send 依赖；DbError 缺少 source |
| 🟢 提示 | 3 | Connection 手动解糖模板代码量大；execute_with_params 误用 Internal 变体；Transaction::execute 错误映射 |

**亮点确认**：
- 核心 trait（`Connection`、`ConnectionFactory`、`Model`、`ActiveRecord`）全部显式 `Send + Sync`
- 生命周期设计合理：单一 `'a` 绑定，所有方法返回 Owned 数据，无借用泄漏
- 公开方法全部使用 `Result`，无未保护的 `unwrap()`/`expect()`
- 错误枚举充分（21+8+10 变体），带错误码系统
