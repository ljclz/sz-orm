## 8. 自适应调优设计说明

### 8.1 连接池自适应

- **决策模型**: `ResizeDecision` 基于当前负载、历史趋势和配置策略决定扩容/缩容/保持
- **安全边界**: 单次调整幅度有上限，防止激进扩缩容导致系统震荡
- **风暴保护**: 高频调整请求被限速，避免在负载波动时频繁调整
- **历史记录**: `AdjustmentHistory` 记录所有调整事件，支持回溯分析

### 8.2 执行计划自适应

- **基线维护**: `PlanExecutionBaseline` 维护滑动窗口统计，回归样本不计入基线（防止污染分布）
- **回归检测**: 基于 P95 延迟和成本偏差检测回归，触发计划切换
- **切换限速**: `PlanSwitchRateLimiter` 防止频繁切换导致系统不稳定
- **索引建议**: `IndexAdvisor` 基于 `QueryFeatures` 和 WHERE 列生成索引建议

### 8.3 可观测性闭环

- **建议生成**: `TuningSuggestionGenerator` 从 RCA 结果映射到具体调优动作
- **自动应用**: `AutoApplier` 通过 `SuggestionExecutor` trait 执行建议，支持 dry-run
- **审计日志**: `TuningAuditLogger` 记录所有自动应用操作，支持回溯
- **闭环协调**: `AdaptiveTuningLoop` 协调检测→建议→应用→验证的完整闭环
