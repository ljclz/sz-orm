## 4. 向后兼容性说明

- PoolConfig 新增 6 个字段全部有 Default 实现，现有 `PoolConfig { ... }` 构造点通过 `..Default::default()` 或显式补充字段兼容
- `PoolConfigBuilder` 新增 `performance_linkage()` 方法为追加方法，不影响现有 builder 链
- `QueryAs` 新增 `linkage` 字段默认 `None`，`with_performance_linkage()` 为追加 builder 方法
- `Pool` 新增 `linkage_metrics` + `diagnostic_report_generator` 字段，`clone()` 中共享/复制，不影响现有 clone 语义
- Pool 新增 5 个 getter：`observability_loop_config()` / `compliance_auto_check_config()` / `diagnostic_report_config()` / `diagnostic_report_generator()` / `self_check_modules()`
- Pool::new() 读取 4 个新增配置并创建组件/执行逻辑（diagnostic_report→创建 generator，self_check_on_start→执行 SystemSelfChecker）
- 所有新配置默认 `enabled: false`，不启用时行为与 v10.0.0 完全一致
