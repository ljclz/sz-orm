## 9. sz-pay 升级路径说明

sz-pay 从 v9.5.0 → v9.5.1 升级步骤：

1. **Cargo.toml**：在 `sz-orm-sqlx` 和 `sz-orm-core` 依赖上启用 `slow-query-capture` + `auto-healer` feature
2. **lib.rs**：`mod db` → `pub mod db`（暴露 db 模块供端到端测试访问）
3. **db.rs**：新增 `init_pool_with_auto_healer`（通过 `AnyPool::factory()` 创建 `Pool` + `AutoHealer::start`）+ `execute_with_slow_query_guard`（`SlowQueryGuard::new` + `execute_with_logging`）
4. **repositories/order.rs**：新增 `batch_reconcile`（`BatchExecutor::new` + `batch_insert`）+ `batch_create_orders`（`SqlRepository::batch_create`）+ `paginate_orders_sql`（`SqlRepository::paginate_sql`）+ `find_orders_with_items`（`EagerLoader::new` + `with_eager_loader` + `find_all_with_eager`）
5. **services/pay_order_service.rs**：新增 `pay_order_orchestrated`（`TransactionOrchestrator` 3 步骤编排：扣款 → 记费 → 记费确认）
6. **tests/wiring_e2e.rs**：新建 5 项端到端测试，验证 5 项新 API 真实接线
