§SZ-ORM C++ Bindings

Provides sz-orm-core’s Pool/Query API to C++ via extern "C" + C ABI (SQLite backend, real and usable).

C++ side wrapper see cpp/szorm.h (use szorm::Pool after #include <szorm.h>).
