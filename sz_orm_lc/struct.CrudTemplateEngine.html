CRUD template engine.

Generates SQL DDL, parameterized CRUD statements, Rust structs, and repository layer code.

pub fn generate_rust_repository(model: &ModelDefinition) -> String

Generate Rust repository layer code (Repository pattern).

C-1 fix: generates real compilable CRUD code that uses sqlx::query to execute parameterized SQL and binds field values via a bind chain. create/update/delete return PgQueryResult; find_by_id returns Option<PgRow> (the caller reads fields via row.get).

The generated code is guaranteed to compile without users filling in placeholders.
